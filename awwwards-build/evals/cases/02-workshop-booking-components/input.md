# Case 02 input

Mode: generation, no browser available.
Stack: plain HTML, CSS and a little JavaScript.

> Design the components for booking a place on a pottery workshop.
> The page lists upcoming workshops as cards, each with a date, a price and the places left.
> Choosing one opens a booking form: name, email, number of places (1 to 4), an optional note, and a checkbox to join the mailing list.
> Places left load from a slow API, often two or three seconds.
> Submitting can fail if the workshop fills up while someone is filling in the form.
>
> Make the buttons minimal, just text that underlines on hover, like the award sites do.
> Show a spinner while things load.
> Validate each field as soon as the person leaves it so they know straight away.
