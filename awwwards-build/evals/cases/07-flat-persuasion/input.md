Mode: acceptance review of a product homepage plan, no browser supplied.

The fictional manufacturer makes adjustable workshop lamps.
The brief requests an expressive, award-caliber product page based on the lamp's articulated arm and focused beam.
Owned photographs, a licensed product model and real specifications are available.
The plan has a static type hero, a specification table, workshop photographs, a care section and a purchase action.
All controls have visible focus and 44px targets.
Every section is marked still because the information is already readable.
The only animation is a 2px button arrow shift and a margin progress line, called the signature moment.
The 3D model is omitted because static content is described as safer and faster without any prototype or measurement.
Reduced motion disables the arrow shift.
