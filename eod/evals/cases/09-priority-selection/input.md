# Case 09 - priority selection

Both scenarios are fictional dictation, with no repository or spreadsheet access.
Run each as a separate reporting day.
The notes are deliberately out of priority order.

## Busy day

Date: 20 August 2026.

```
eod 8/20

Northbank logo. Small spacing fix, it's live. Took a few minutes.

Report workflows. That's where most of the day went. Pretty happy, we can
finally send the right report to each client. Fixed who gets which report.
The report sheet is done. Monthly report is still missing the late payments,
not done, gonna finish that tomorrow.

Task management, put owners and due dates on the overdue client jobs.
The team can see what's waiting on them now. Done.

Booking forms, fixed the confirmation that was sending people to the wrong
day. Bookings were being missed, tested it with two bookings, all good now.

Client handoff, sent the welcome pack and access instructions. They're
waiting on us for the training date, still need to arrange that tomorrow.

Northbank logo again, checked the spacing, checked the preview, checked it
on the site, saved it, checked it again. Looks good. That was the last thing.
```

## Design-focused day

Date: 21 August 2026.

```
eod 8/21

Report sheet, fixed a heading. Five minutes, done.

Northbank identity is the main priority today, the client needs the new logo
for Monday's launch. Spent most of the day on it. Logo is done, the shapes
and spacing are where we wanted. Sent it to the client, waiting on sign-off.
The brand sheet is started, still need the small-size version tomorrow.

Booking forms, checked the confirmation from yesterday. Still working,
nothing new there.
```
