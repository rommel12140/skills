# A sibling mark, its sign-in screen and a hero

Mode: Refine.
A fictional software company has an accepted parent wordmark with square corners, icons drawn on one stroke weight, and a teal and slate palette.
It is launching a second product and asks for a mark that belongs to the family, plus a sign-in screen and a hero for the product's page.
No browser or implementation fixture is supplied.
Work only from the following synthetic observations.

- A first mark used rounded corners, a purple accent and a script face; it was rejected as unrelated to the family.
- A second mark was the parent wordmark with the product name swapped in on the same letterforms; it was rejected as a copy.
- In the current draft mark, the E has square corners and the O has rounded ones, and the O looks wider than the E although both boxes are 40px wide.
- The sign-in screen uses its own button style, a different input height and a gradient ground; the main product screens use the shared button and input components.
- The four plan cards under the hero have three different heights because their descriptions differ in length; an earlier fix clipped the longest description to two lines.
- At 1440px wide the hero places a product object between the two words of its headline; at 1024px after a resize the object overlaps the second word, and at 390px it sits far right with no relation to the type.

Describe the corrections and the evidence you would show.
Do not claim a rendered pass.
