# Expected decisions

Do not issue `CP1` or `X2`: these numbers and contents serve an actual reference task.
Record the accepted common display family as a `T1` exception.
Do not prescribe an arbitrary second typeface for `T2`; inspect the stated role contrast when rendering is available.
A flat surface system is not `K1`, which concerns uniform rounding and elevation applied indiscriminately.
Do not add a cinematic hero, testimonial area or decorative motion.

`X1` remains unchecked because its required visual-language document is absent.
The brief still supports a useful context-fit discussion.
Rendering is required before claiming actual contrast, typography, reflow or focus visibility passed.
If a browser reveals a real defect, report it with evidence even though the fixture is intended to be restrained.
The fixture is a false-positive guard, not a command to suppress actual accessibility failures.
