# Context fit

Mode: Audit.
An operations application is for comparing reservation times and resolving unassigned orders.
The accepted product identity uses a restrained sans family and a compact neutral interface.
The current proposal adds a large display serif, tilted receipt-shaped panels, a dark green side block and an italic slogan.
The designer argues that all these choices relate to hospitality.

The supplied observation is that less operational data is visible, times no longer align, and the primary action looks like text in the receipt.
There is no `voice.md`, but the task and accepted baseline above are explicit.
Review the reasoning and prescribe a scoped correction without changing files.
