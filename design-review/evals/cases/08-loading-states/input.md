# Loading and recovery

Mode: Refine.
Stack: React with Tailwind.
A dashboard has a persistent heading, filter bar, summary and data table.
During every refresh, the whole page becomes a bare loading sentence.
Rows jump into place on success.
An empty response and a failed response both leave the same sentence indefinitely.
A partial failure discards rows already loaded.

The request also covers a brief session check before the destination layout is known.
The accepted identity permits a short branded status animation for this check.
Define the corrected states without adding artificial delays.
